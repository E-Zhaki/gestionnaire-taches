# Gestionnaire de tâches

Application web pour gérer une liste de tâches : ajouter, modifier, supprimer, filtrer et rechercher.
Projet réalisé en binôme en HTML, CSS et JavaScript.

## Fonctionnalités

- Ajouter une tâche (titre obligatoire, description, statut)
- Afficher les tâches sous forme de cartes colorées selon le statut
- Modifier une tâche
- Supprimer une tâche
- Filtrer par statut : toutes, à faire, en cours, terminées, bloquées
- Rechercher dans le titre et la description
- Sauvegarde automatique dans le localStorage

## Lancer le projet

1. Cloner le dépôt :
   `git clone https://github.com/E-Zhaki/gestionnaire-taches.git`
2. Ouvrir le dossier dans VS Code.
3. Ouvrir `index.html` avec Live Server (ou directement dans le navigateur).
